# Primeiro teste controlado

Para evitar uma alteração acidental em vários itens, use apenas um registro conhecido.

1. Abra o sistema e faça login.
2. Pesquise pelo nome ou ID do item.
3. Anote o Gestor e Revisor atuais no Monday.
4. No sistema, altere somente o Revisor.
5. Clique em `Salvar no Monday`.
6. Confirme a alteração.
7. Atualize o item no Monday e confira o novo responsável.
8. Se estiver correto, repita o teste com o Gestor.

Se a função retornar erro de coluna, confira no Monday se os títulos continuam sendo `Gestor de Validação - NQ` e `Revisor Validador`.
