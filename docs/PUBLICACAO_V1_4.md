# Publicação da V1.4

## 1. Atualizar o GitHub Pages

Envie todo o conteúdo deste pacote para a raiz do repositório
`Gest-o-Validadores-Monday`, substituindo os arquivos existentes.

O arquivo `index.html` deve ficar diretamente na raiz. Não envie a pasta
externa do pacote e não envie a pasta `.git`.

## 2. O que mudou

- cada grupo passou a ter cabeçalho próprio e cor de status;
- o nome do grupo não se repete em todas as linhas;
- os grupos podem ser recolhidos e expandidos;
- cada grupo carrega 30 itens por vez, com botão `Mostrar mais`;
- os filtros, a busca e a gravação no Monday foram preservados;
- nomes e e-mails duplicados no seletor foram simplificados.

## 3. Supabase

Não é necessário publicar novamente a Edge Function para esta versão. A V1.4
altera apenas a interface do GitHub Pages.

## 4. Validar a publicação

1. Aguarde o GitHub Pages concluir a publicação.
2. Abra o site com `Ctrl + F5` ou em uma janela anônima.
3. Confirme que os grupos aparecem em blocos coloridos.
4. Recolha e expanda um grupo.
5. Use `Mostrar mais` em um grupo com mais de 30 itens.
6. Pesquise um item e aplique o filtro de grupo.
7. Faça um teste controlado alterando somente um Revisor Validador.
