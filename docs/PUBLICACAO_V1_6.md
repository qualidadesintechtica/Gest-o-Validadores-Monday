# Publicação da V1.6

1. Extraia o ZIP.
2. Envie `index.html`, `login.html`, `VERSAO.txt`, `README.md` e as pastas
   `css`, `js` e `docs` diretamente para a raiz do repositório.
3. Confirme o commit na branch `main`.
4. Aguarde a execução do GitHub Pages ficar verde.
5. Abra o site e pressione `Ctrl + F5`.

Não altere a Edge Function nem os secrets nesta atualização.

## Confirmação visual

Na linha de status do quadro deve aparecer:

`Controles V1.6 ativos`

Se essa mensagem não aparecer, o navegador ainda está usando o `index.html`
antigo ou o GitHub Pages ainda não publicou o commit novo.

## Teste rápido

1. Clique em `Criar material` e feche a janela.
2. Clique em `Pessoa`, `Filtro`, `Ordenar` e `Agrupar por`.
3. Abra `Ocultar` e desmarque uma coluna.
4. Clique em `Sem Gestor` e depois em `Quadro principal`.
5. Abra um grupo e altere um responsável.
6. O botão `Salvar no Monday` deve ser habilitado somente após a alteração.
